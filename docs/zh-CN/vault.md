## 保险库


一个加密的凭据仓库：既有不属于某台服务器的凭据 —— 云登录、API key、许可证密钥 —— 也有属于某台服务器的。一台服务器的密码、**一把 SSH 密钥的密钥内容**、一个数据库密码，以及**整条数据库连接串**，都可以是同一条保险库记录：被所有用到它的连接引用、轮换时只改一处、并随一份加密备份被带到另一台机器。

- **AES-256-GCM**，密钥由你的主密码经 **scrypt** 派生
- 主密码**从不保存**；密码错误会导致认证标签校验失败
- 条目可存 URL、用户名、密码、备注、标签，以及**任意多个自定义键值字段**，每个都可标记为机密
- **搜索会匹配每一个字段**，因此你可以按主机名或用户名找到条目，而不只是靠标题

> 一旦丢失主密码就**无法恢复**。这正是它的意义所在。

### 里面可以放什么

| 凭据 | 说明 |
|---|---|
| 服务器密码 | 添加服务器时默认存入保险库 |
| **SSH 私钥** | 存的是**密钥本身**，而不是它的路径 —— 因此它能随备份迁移，而文件名永远做不到。选中一把密钥后，「添加服务器」会询问是否存入 |
| 服务器密钥口令 | 与密钥同存于那条 `sshkey` 记录上 |
| 数据库密码 | 默认存入保险库 |
| **数据库连接串** | 整条 URI，密码就在其中 |
| CI/CD API 令牌、VPN 与隧道密钥、S3 备份密钥、计划备份的口令 | 只存在保险库中；它们本来也没有别处可放 |

操作系统钥匙串仍然是兜底 —— 用于你选择不放进保险库的东西，以及少数无法由保险库托管的东西，因为它们在有人输入主密码之前就需要用到。

### 已保护（secured）与已锁定（locked）

保险库有两种关闭状态，区别在于**什么会停下来**。

**已保护**是十五分钟不碰保险库的结果：条目会从屏幕和应用窗口中清掉，再看它们需要主密码。**其余一切照旧**：你的连接、后台检查、流水线轮询与计划备份继续使用库中的凭据。这个计时器度量的是**你** —— 一次监控采样去读凭据不算你在用保险库，也不会推迟它。

**已锁定**才是完全停止 —— 密钥已从内存中消失，在你解锁之前没有任何东西能解析凭据。它发生在你退出时、按下 **立即锁定** 时，以及机器**休眠**时。锁屏只会让保险库进入「已保护」，而不是「已锁定」，因为屏保是你离开座位，不是机器关机。

有一个例外，而且是你自己打开的。若你启用 **Touch ID 解锁**（仅 macOS）并选择跨重启保留，保险库派生密钥的一份副本会留在磁盘上、由操作系统钥匙串包裹，于是你的指纹可以在不输入主密码的情况下打开保险库。此时「已锁定」仍然意味着本进程内无法解析凭据，但不再意味着密钥只存在于你的记忆里。默认的「仅本次运行」设置会把这份副本留在内存中，并在应用退出时丢弃。

这个划分是刻意的，理由写在 [SECURITY.md](../../SECURITY.md) 里：空闲计时器真正能保护的，是窗口里那些已解密的条目，而阻止一个监控工具去监控，对此毫无帮助。

## 备份与恢复


设置 → **备份与恢复** 会把一切导出成**单个口令加密文件** —— 工作区、服务器、数据库、隧道、已保存的凭据、保险库、工作区密码与受信任的主机密钥。

磁盘上的凭据由你的操作系统钥匙串封存，而钥匙串绑定到那台机器与那个用户，因此把配置目录复制走没有意义。备份会解开它们，并用你的口令重新加密全部内容，从而使它**可以迁移到任何机器**。

只要你的连接发生变化，就会出现红色的 **备份已过期** 提示，让你知道上一次导出已不再反映现实。

## 设置


![设置](../images/settings-general.png)

| 分区 | 涵盖内容 |
|---|---|
| **通用** | 版本与更新检查 —— 通道、频率、自动下载、退出时安装 —— 以及引导流程 |
| **外观** | 主题（OpsMaxx 为默认 / OpsMaxx 浅色 / 经典深色 / 经典浅色 / 跟随系统）与界面密度 |
| **终端** | 字体、**字号**（也可用 <kbd>Ctrl</kbd>+<kbd>+</kbd>/<kbd>-</kbd>）、**配色方案**（见[终端](../terminal.md)）、光标闪烁、滚动行为 |
| **连接** | 新建连接的默认值 |
| **SSH** | **已认证连接在最后一个会话关闭后保留多久**，以及一份共享连接的实时列表和一个「断开」按钮 |
| **安全** | 凭据存储、**保险库在屏幕上停留多久**、工作区锁定，以及**受信任的 SSH 主机密钥**列表和一个「忘记」按钮 |
| **SFTP** | 文件传输偏好 |
| **监控** | **警报**（默认开启 —— CPU、内存、失败单元与 webhook 的总开关）、阈值、**在后台检查服务器**及其频率、**webhook 投递**，以及监控条 |
| **模块** | 可选的资产模块，每个一个开关 —— 全新安装时二十一个里有八个是开启的，而所有会写入的都关闭。见[监控与集群运维](../monitoring.md) |
| **编辑器** | 内置文件编辑器 |
| **快捷键** | **重新绑定任意快捷键**、清除、恢复默认、导出/导入，以及 <kbd>Ctrl</kbd>+<kbd>1</kbd>…<kbd>9</kbd> 是否包含已隐藏的工作区 |
| **备份与恢复** | 加密导出与导入 |
| **通知** | 警报与 toast 提示 |
| **高级** | 诊断与重置 |

若你的服务器用了双因素认证，**SSH → 已认证连接保留时长**这条设置最值得了解：连接存活期间，新会话、文件浏览与监控都会复用它，因此验证码只需输入一次，而不是每次都要。
