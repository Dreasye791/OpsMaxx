## 功能


| | |
|---|---|
| **SSH 终端** | 完整的 xterm 终端，GPU 渲染，支持搜索、分屏、选中即复制与可调缩放 |
| **本地终端** | 在同一标签栏中并排放置你自己的 zsh、bash、PowerShell、Git Bash、MSYS2 或 WSL —— 按平台自动发现，macOS 上用登录 shell，且任何 AI 代理都触及不到 |
| **跳板机 / 堡垒机** | 每台服务器可串联无限级跳转，每级都有自己的凭据 |
| **云服务器** | 把 Google Cloud、AWS 与 Azure 机器当作普通服务器 —— 通过你已有的 `gcloud`、`aws` 或 `az`，用你已有的登录态。不保存任何云凭据，而拿到的是真正的 SSH 会话，因此文件、监控等等都可用 |
| **双因素认证** | 能够应答 keyboard-interactive 挑战；连接会被共享，因此验证码只需输入一次，而不是每个会话都要 |
| **SFTP 浏览器** | 在同一条连接上浏览、编辑、上传、下载、重命名与删除，并带有可取消的传输队列 |
| **远程桌面** | 在标签页中 RDP 连 Windows 主机，主机只能经堡垒机到达时就经堡垒机 —— 首次使用时固定服务器证书 |
| **服务器监控** | 停靠在终端下方的实时 CPU、内存、磁盘与网络，并对 CPU、内存与失败的 systemd 单元发出警报 |
| **后台检查** | 按计划对每台服务器采样，于是发烫的服务器或凌晨三点挂掉的单元，会在你看别处时被注意到 |
| **Webhook 警报** | 把警报 POST 到 Slack、Discord、Teams 或任意 HTTPS 端点 —— 只带友好的服务器名与触发了什么，绝不含主机名、IP 或日志行 |
| **SSH 隧道** | 本地转发、远程转发与 SOCKS5 代理 |
| **WireGuard** | 用户态 WireGuard，**无需管理员权限** —— 隧道体现为本地 SOCKS5 代理与转发，你的路由表不会被触碰 |
| **OpenVPN** | 在 macOS 与 Linux 上随应用打包，经其管理接口驱动，支持一次性验证码与分流 |
| **frp** | 通过 frp 服务器发布本地端口，每个代理都有一句确认，指名到底什么会变为可达 |
| **流量检查器** | 读取某台机器实际发出的 HTTP 与 HTTPS —— 一个 Burp / Fiddler 式代理，一键安装证书，终端与 SSH 会话自动走它，对证书做固定的主机会被指名而不是悄悄漏掉 |
| **经 VPN 的 SSH 与数据库** | 让某台服务器或数据库指向一个 VPN 配置，它会随会话建立、等待就绪、并随会话拆除 |
| **HTTP 客户端** | REST、WebSocket 与 GraphQL 请求从本机发出、经服务器的 SSH 连接、或走 VPN —— 绑定在服务器回环地址上的服务只有一次请求之遥。集合、带生产环境确认的环境变量、cURL 与 OpenAPI 导入，以及自动隐藏凭据的「复制为 cURL」。[使用方法](../08-user/guides/http-client.md) |
| **数据库** | PostgreSQL、MySQL、SQL Server、MongoDB 与 Redis —— 每种引擎都配一个交互式 shell |
| **经 SSH 的数据库** | 连到只能经堡垒机路由的数据库 |
| **保险库** | AES-256-GCM 加密存储，可放 URL、登录名、API key 与任意键值对 |
| **工作区** | 按客户或环境彼此隔离的空间，可选密码保护 |
| **加密备份** | 单个口令保护的文件包含全部内容，可跨机器迁移 |
| **主机密钥校验** | 首次使用即信任（TOFU），密钥一旦变更则硬性中止 |
| **可重绑的快捷键** | 每个快捷键都可按上下文重绑，带冲突检测与导出/导入 |
| **AI 与 MCP** | 让 Claude Code、Claude Desktop、Codex 等 MCP 客户端操作你的服务器 —— 受访问组限定范围，敏感操作需人工审批 |

集群运维 —— <kbd>Ctrl</kbd>+<kbd>M</kbd>。其中大多数是 *设置 → 模块* 里的可选**模块**。八个出厂即开启，而这八个全都只读；**所有会写入的 —— 打补丁、在所有机器上执行命令、作业、吊销密钥 —— 在你打开之前都是关闭的**，且升级绝不会为某个安装开启它原本没有的模块：

| | |
|---|---|
| **资产清点** | 每台服务器、其操作系统与版本、有哪些待处理项，以及最后一次见到它是什么时候 |
| **补丁** | 每台服务器待装什么，按波次应用；一旦有服务器回来时状态不健康就停下，而不是继续往前推 |
| **在所有机器上执行一条命令** | 向选中的服务器广播，先给一句指名「在哪台机器上跑什么」的确认，逐服务器给出结果，并且作业能在应用被关闭后继续。可以把作业的步骤存成模板复用 —— 模板从不记录服务器，代理读不到它们，且只留在本机：不同步、也不进备份 |
| **日志跟踪** | 在一个面板里同时跟踪多台服务器上的同一个文件 |
| **全资产搜索** | 在已经采集到的数据里搜索，完全不碰服务器 |
| **Docker** | 容器、镜像与卷，每项体积如实给出；按 id 回收，且恰好回收预览里展示的内容 —— 从不盲目 `prune` |
| **Compose** | 读取某个项目的服务、它们的状态，以及相对于磁盘上文件的漂移 |
| **Kubernetes** | 工作负载、封锁（cordon）、排空（drain）与 exec —— 排空有七种拒绝理由，并把「读取没有返回结果」本身就当作一种拒绝 |
| **数据库运维** | PostgreSQL、MySQL/MariaDB、SQL Server、MongoDB 与 Redis 的复制延迟、慢查询、表体积与连接数 —— 客户端支持的每一种引擎都有 |
| **备份** | 按计划导出到本地路径或兼容 S3 的存储，并**以恢复来验证**，而不是检查文件是否存在 |
| **安全态势** | SSH 配置、sudo 规则、监听端口与防火墙状态，按它们在服务器上的真实样子读取 |
| **防火墙规则** | 规则本身而不只是条数 —— 默认关闭、有自己的同意步骤、从不保存，且任何设置下 AI 代理都读不到 |
| **配置漂移** | 自你上次查看以来，某台服务器上发生了什么变化 |
| **容量趋势** | 磁盘与内存的走向，来自已经采集的历史 |
| **规则** | 「触发这个就运行那个」 —— 而运行所需审批与人工执行时完全相同 |
| **Cron** | 读取与编辑 crontab，先针对服务器做计划、再经审批写入 |
| **运行手册** | 某个警报上一次在那台服务器上触发时，最近三次各运行了什么 |
| **CI/CD** | Jenkins、GitLab 与 GitHub Actions 的流水线、运行历史与失败步骤的日志，就放在这次运行改动的服务器旁边。只读：这个标签页上的任何东西都不会启动、重跑或取消构建。默认关闭，原因与其他只读模块不同 —— 开启后会用你提供的长期令牌定时轮询第三方的 API，而它渲染的内容由开合并请求的人写成 |
| **变更日志** | 谁批准了什么、何时批准、做了什么 |
| **访问与密钥** | 哪把密钥能打开哪台服务器，以及它属于谁 |
| **受管进程** | 让本地进程持续运行，且不自动启动任何东西：重启后存活的是那份清单，而不是某个正在运行的命令 |
| **界面语言** | 英文与简体中文 —— 在 **设置 › 语言** 中切换，或设为跟随操作系统。这里指应用本身：文档仍为英文。翻译层的机制与尚未翻完的部分见 [i18n.md](../i18n.md) |

## 真实使用场景


- **生产故障排查** —— 让代理用大白话里的服务器名去查服务状态、跟踪日志，或采样 CPU/内存，而从不把那台服务器的密钥交给它。
- **堡垒机 / 跳板机运维** —— 同一套友好名称解析在串联跳转中同样有效；被限定在堡垒机之后某个工作区的代理，同样不需要堡垒机的凭据。
- **数据库排查** —— 被允许 `databaseAccess` 的代理可以查询只能经 SSH 隧道到达的数据库，与人手动访问时走的是同一条路。
- **日志排查** —— **只读**或专门建的「仅日志」访问组，让代理能在指名的服务器上读取并总结日志，且没有任何修改的途径。但这不是跨资产的：**只读**拒绝 `fleetRead`，桥上的任何工具都不能在一次调用中跨整个资产跟踪或搜索日志。
- **受控的生产变更** —— 把要紧的能力设为 **ASK**（先询问）；于是改配置或重启会等你的明确批准，而不是无人值守地执行。
- **广义的 AI 辅助运维** —— 你手动使用的终端、SFTP、数据库与监控工具同样对代理开放，按工作区与访问组限定范围，就像多了一双更受约束的手。

## OpsMaxx 与 MobaXterm、PuTTY、Termius、SecureCRT 的对比


如果你在找一个**免费的 MobaXterm 替代品**、一个**现代的 PuTTY 替代品**，或者一个不把你保存的服务器锁进订阅的**开源 Termius 替代品**，这里是简版：

| | **OpsMaxx** | MobaXterm | PuTTY | Termius | SecureCRT |
|---|---|---|---|---|---|
| 价格 | **免费，MIT** | 免费版 + 付费 Pro | 免费 | 免费版 + 付费 Pro | 付费授权 |
| 开源 | **是** | 否 | 是 | 否 | 否 |
| Windows / macOS / Linux | **三者全支持** | 仅 Windows | 三者全支持 | 三者全支持 | 三者全支持 |
| 需要账号 | **不需要** | 不需要 | 不需要 | 同步需要 | 不需要 |
| 遥测 | **无** | 有部分 | 无 | 有 | 有部分 |
| 保存会话数上限 | **不限** | 免费版 12 个 | 不限 | 免费版受限 | 不限 |
| 串联跳板机 | **不限** | 支持 | 需手工 | 支持 | 支持 |
| SFTP 浏览器 | **内置** | 内置 | 需另装 | 内置 | 内置 |
| SSH 隧道 + SOCKS5 | **支持** | 支持 | 支持 | 支持 | 支持 |
| 数据库客户端 | **PostgreSQL、MySQL、SQL Server、MongoDB、Redis** | 无 | 无 | 无 | 无 |
| 加密密钥保险库 | **有，AES-256-GCM** | 密码存储 | 无 | 云端保险库 | 无 |
| 实时服务器监控 | **有** | 基础 | 无 | 无 | 无 |
| 可重绑快捷键 | **全部可重绑** | 部分 | 部分 | 部分 | 支持 |
| AI 代理接入（MCP） | **支持，按访问组限定** | 无 | 无 | 无 | 无 |

真正的差异点在**数据库客户端与保险库**。上表里其他工具，在你需要查一张表或找一条 API key 的那一刻，都会把你推到另一个应用去。
