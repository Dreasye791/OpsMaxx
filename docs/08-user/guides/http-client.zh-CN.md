# HTTP 客户端

在 OpsMaxx 里直接发出 REST、WebSocket 与 GraphQL 请求，走的是你终端所用的同一条路径。

[English](http-client.md) · **简体中文**

## 目标

这个 HTTP 客户端是一个 API 客户端，但有一处真正要紧的不同：**请求从你选择的地方发出**。可以是本机、你某台已保存的服务器（经它的 SSH 连接），或者一个 VPN 配置。因此经 `web-01` 发出的 `http://localhost:8080` 能到达 web-01 回环地址上的服务，而 `gitlab.internal` 会在那台服务器的网络里解析。没有任何东西被暴露，也不必手工开隧道。

请求由 OpsMaxx 的主进程发出，而不是由窗口发出。这意味着：

- 没有 CORS 规则；
- 可以为某一个集合信任一个私有证书颁发机构，同时仍保持证书校验；
- WebSocket 握手可以携带真实的头，例如 `Authorization`。

读完这份指南，你就能发出请求、把它保存下来、分别对着开发与生产环境运行，并导入你已有的东西。

## 步骤

### 1. 发出第一个请求

1. 在活动栏里打开 **HTTP**。在没有任何标签页打开时，工作台会显示一行空的 URL，直接可以输入。
2. 粘一个 URL，或者整条 `curl …` 命令，然后按 **⌘↵**（Windows/Linux：**Ctrl+Enter**）。
   粘进来的命令会变成请求：方法、头与请求体都被填好，被忽略掉的内容会以提示条列出（见第 7 步）。
3. 响应出现在请求旁边；窗口较窄时出现在它的下方。

不带协议输入的 URL 会自动补上：

- `localhost`、回环地址、`10.x`、`172.16–31.x`、`192.168.x`、单标签主机名与 `*.internal` 用 `http://`；
- 其他一切用 `https://`。

### 2. 构建一个 REST 请求

- **方法与 URL。** 查询参数与 URL 双向保持同步。被禁用的行仍留在表里，但不进 URL。`:id` 与 `{id}` 这类路径段会列在 **Path parameters**（路径参数；这一处目前仍显示英文）下。
- **变量。** 在任何地方写 `{{name}}`。悬停某个记号，或把光标放进去按 **⌘I**（Ctrl+I），就能看到它的值以及它来自哪里。若某个记号无法解析，OpsMaxx 会在发送前停下并指名它。补上它，或选择 **Send anyway**（仍然发送；当该记号位于 URL 的主机部分时不会提供这个选项）。
- **认证。** 类型有：继承自集合、无认证、Bearer 令牌、Basic，以及 API key（头或查询参数）。
  - 以明文输入的机密会被发送，但**不会被保存**。该字段会显示「Not saved — kept for this session only」（未保存 —— 仅保留于本次会话），并提供 **Move to vault…**，它会在需要时创建或解锁[保险库](../../vault.zh-CN.md)，并用 `vault:` 引用替换掉那段文本。
  - 引用在发送时解析：在头、URL、认证字段与表单行里都有效。它们**绝不**在 JSON、XML 或纯文本请求体内解析，因为服务器可以把请求体回显出来。
- **头。** 有些头是 OpsMaxx 自己设置的。在「布局」菜单里打开 **Auto-generated headers**（自动生成的头；这一处目前仍显示英文）即可看到它们，以及每一条存在的原因。
  - `User-Agent`、`Content-Type`、`Authorization` 与 `Cookie`：你自己写的一行会替换掉对应的那一条。
  - `Content-Length` 与 `Host`：由连接设置，无法覆盖。
- **请求体。** 模式有：无、JSON、文本、XML、表单 URL 编码、Multipart（每行一个文本或文件字段）与二进制文件。
  - 文件只保留在内存中。重启之后，该请求会显示 **Choose the file again**（重新选择文件；这一处目前仍显示英文）。
  - 超过 256 KiB 的请求体会被发送，但不会被保存。
- **设置。**
  - **Timeout**（超时；这一处目前仍显示英文）：用集合的默认值，否则 30 秒，上限 10 分钟。
  - **Follow redirects**（跟随重定向；这一处目前仍显示英文）：开启。**Max redirects**：5。重定向到另一台主机会丢掉你的凭据、路径与所有证书例外；而一个会把请求体重新发往另一台主机的 307 或 308 会被拒绝，并给出理由。

**读响应。**

- **Body** 有三个视图：美化、原始与预览（用于 HTML 与图片）。预览是离线的：脚本与远程资源都被拦下，SVG 以图片方式显示。
- 其余标签是 **Headers**、**Cookies** 与 **Timeline**。时间线显示实际发出去的内容，凭据已遮罩。
- 在请求体上右键可以：
  - 查找（**⌘F**）、自动换行、全部折叠 / 全部展开；
  - **Copy value** 与 **Set as variable…**，作用于光标所在的那个 JSON 值。当该值看起来像凭据（一个令牌，或 `access_token` 这样的名字）时，对话框会警告「变量会以明文保存并同步」，并提供 **Store in vault…**；
  - **Copy response** 与 **Save response to file…**。保存从你的下载目录开始，并原样写入字节。

响应带来的 **Cookies** 会进入一个 cookie 罐，存活到你退出 OpsMaxx。这个罐**按工作区**、**也按路径**区分，因为经 `web-01` 的 `localhost` 与本机的 `localhost` 不是同一台机器。`Secure` cookie 绝不会经 `http://` 发出。**布局 ▸ Cookies…** 可以查看并清空这个罐。

### 3. WebSocket

**+ 新建 ▸ 新建 WebSocket**，然后按 **⌘↵**（Ctrl+Enter）连接。

- 握手头与子协议来自该请求。
- 连上之后，**⌘↵** 会把编辑器里的消息以文本或 JSON 发出。**⌥⌘B**（Ctrl+Alt+B）美化它。**⌘↵** 永远不会断开连接。
- 日志为每个标签保留最近 5,000 帧，且可以搜索与过滤。
- 在某帧上右键可以复制它、载入编辑器、重发或保存。

### 4. GraphQL

**+ 新建 ▸ 新建 GraphQL 请求。** 该请求有查询、认证、头与设置四个标签。

- 第一次成功**运行**就会经同一条路径加载 schema；Schema 浏览器里的 **Load schema** 可以按需加载。此后查询编辑器会自动补全字段与参数，浏览器里可以浏览类型。
- 变量是 JSON，位于查询下方可折叠的 Variables 面板里。
- **Prettify**（**⌥⌘B** / Ctrl+Alt+B）格式化查询。
- 当一个文档里有多个操作时，**运行**会按名字逐个提供。发往生产的 mutation 会先询问（第 5 步）。

### 5. 保存、组织与切换环境

- **保存。** **⌘S**（Ctrl+S）把请求保存进一个集合。集合可以包含文件夹与请求，并拥有自己的变量、默认认证与连接设置。
  - **已保存的请求，从它所属集合的路径发出。** 当这与该请求此前使用的路径不一致时，保存对话框会说明这一点。
  - 在树里，**F2** 重命名，**Delete**（macOS 为 **⌘⌫**）删除，**⌘Z**（Ctrl+Z）撤销上一次删除。
- **环境**为每个环境保存变量。**⌘E**（Ctrl+E）打开选择器。作用域最窄者胜：环境 → 集合 → 全局。
  - 在一个环境上勾选 **Production**。当名字里含 `prod` 或 `production` 时会自动勾上。
  - 生产目标会在 URL 行上显示一条红色标线和一个 `PROD` 徽标。
- **生产确认。** 在下列任一操作发往生产目标之前，OpsMaxx 会问「Send … to production (…)？」：
  - POST、PUT、PATCH 或 DELETE；
  - GraphQL mutation；
  - WebSocket 的连接或消息。

  生产目标指的是：一个生产环境，或一条经标记为 `prod` / `production` 的服务器走的路径。这个确认覆盖所有发送方式：按钮、**⌘↵**、命令面板与历史。「Don't ask again this session」只对那个环境或服务器、以及那一个动作生效。
- **历史**列出你发出过的东西，按日期分组且可搜索。**Send again** 与 **Open as new request** 会保留原路径。如果那台服务器或那个 VPN 配置已被删除，该请求会被拒绝，绝不会改从本机发出。
  - 对一个仍然保存在案的请求点「再次发送」，发送的就是它现在的样子。
  - 否则请求会从历史里重建，而历史里那些名字像凭据的值已被遮罩。这些字段会标为「Not kept」，在你重新输入之前该请求不会发送。

### 6. 选择请求从哪里发出，以及如何校验证书

- **发送自**是 URL 行上的路径标签：本机、某台已保存的服务器，或某个 VPN 配置。
  - 新建的、未保存的请求自己持有路径。
  - 已保存的请求用其集合的路径。可以从标签处改，也可以在 **集合 ▸ 连接** 里改。
- 除非你在 **集合 ▸ 连接** 里按集合改动，**证书**都会被校验。
  - **Verify certificates**（校验证书；这一处目前仍显示英文）。关掉它会要求你确认，之后该集合里每个请求上都会一直挂着一个红色的 **TLS unverified**（TLS 未校验；这一处目前仍显示英文）标签。
  - **自定义 CA。** 选一个 PEM 文件，或粘贴一个。只保留 `-----BEGIN CERTIFICATE-----` 块，含私钥的文件会被拒绝。信任一个 CA 同样需要你确认。
  - 不属于任何集合的请求始终执行校验。
  - 如果另一台已同步的设备关掉了校验或改了 CA，该集合会显示一次性提示，请你复查。
- **生成代码：** 请求工具栏上的代码按钮会打开一个抽屉，把该请求呈现为 cURL、fetch、Python（requests）、Go 或 HTTPie。它的遮罩方式与「复制为 cURL」相同，而 **Include secrets…** 会先询问。
- **复制为 cURL：** **⇧⌘C**（Ctrl+Shift+C），在发送菜单里，或从树中的某一行。
  - 它**默认遮罩凭据**。保险库的值、名字像凭据的头、查询值与表单字段，以及 URL 里的密码，都会变成 `{{name}}` 或 `<secret>`。
  - **Copy as cURL (with secrets)…** 会先询问。
  - 每个参数都用单引号包裹，因此这条命令可以安全地粘进 shell。

### 7. 导入，以及复制为 cURL

**导入**在侧边栏标题处，或按 **⌘O**（Ctrl+O）。

- **cURL。** 粘一条命令，看预览，然后**在新标签中打开**或保存进某个集合。命令里的任何东西都不会被执行。
  - `$(…)`、反引号与 `$VAR` 会完全按你写的保留。
  - 下列参数**永远不会被采纳**，只会被报告出来：
    - 文件引用（`-d @file`、`-F f=@file`、`-T`、`-K` 之类）：只保留文件名，由你重新选择文件；
    - `-k` / `--insecure`：证书仍然会被校验；
    - 代理类参数：请改用**发送自**；
    - `--cacert`、`--cert`、`--key`；
    - `--location-trusted`、`--resolve`、`--connect-to`、`--unix-socket`、`--interface`。
- **OpenAPI**（JSON 或 YAML；Swagger 2 会被升级）。可以从一个 URL 经你选择的路径获取，或选一个文件。
  - Tag 会变成文件夹，`servers[0]` 会变成该集合的 `baseUrl`。
  - 只跟随文档内部的引用。指向其他文件或 URL 的引用会被计为「N external references not followed」，并且永远不会被获取或读取。
  - **重新导入**会在你确认后替换该集合的请求。

### 9. 知道什么存在哪里

| 内容 | 位置 | 是否同步 / 备份 |
|---|---|---|
| 集合、文件夹与请求，及其变量、认证、路径与证书设置 | 应用的数据文件 | 会被同步（如果你用了同步）并备份 |
| 环境与全局变量 | 应用的数据文件 | 会被同步并备份 |
| 打开的标签与未保存的草稿 | 应用的数据文件 | 进备份（用备份口令加密，已输入的凭据已被剥离），**从不**同步 |
| 请求历史 | 本设备上它自己的文件 | **从不**同步或备份 |
| 响应、cookie、WebSocket 日志、GraphQL schema、选中的文件 | 内存 | 退出即消失 |

- **手输的凭据不会被保留。** 在任何内容被保存或同步之前，OpsMaxx 会移除下列内容，除非它们是 `{{变量}}` 或保险库引用：
  - 认证的机密码字段；
  - `Authorization`、`Proxy-Authorization` 与 `Cookie` 头的值；
  - URL 里的密码。

  其他看起来像凭据的值，比如 `X-Api-Key` 头或一个装着令牌的变量，会按原样保存，并给出提醒，提醒里提供 **Move to vault…**。
- **历史：**
  - 用你操作系统的密钥环封存。在没有密钥环的机器上（某些 Linux 桌面），它只保留本次会话，历史面板会说明这一点；
  - 保留 30 天或 2,000 条，先到者为准；
  - 保存的是名字像凭据的值已被遮罩的请求，外加响应的状态、体积与耗时；
  - 从不保存响应体、cookie 或 WebSocket 帧。

  **Clear history** 会删除该文件，**Delete all data** 同样如此。

### 10. 从 OpsMaxx 0.51.x 升级

旧客户端的集合与环境会在新客户端首次打开时转换，并有一条横幅报告搬了什么。

- 由 OpenAPI 描述生成的集合可能需要**重新导入**。若是文件，请再次选择同一个文件：之前只保留了它的名字。
- 旧的 cookie 会被清空。
- 任何无法转换的内容都会被另存一旁，而不是丢弃，横幅会说明有多少条。
- 在旧版「认证」面板里手输的凭据从未被保存。请重新输入，最好改用保险库引用。
- **Recover old data…** 会从旧数据的副本再跑一次转换。它只新增集合，绝不覆盖已有的。

## 验证

- 经某台服务器发出的请求，会在响应的状态行以及**时间线**里显示「via」那台服务器。
- **时间线**与**复制为 cURL** 显示的是 `{{name}}` 或 `<secret>`，永远不是保险库里的值。
- 重启之后，以明文输入过的认证字段会显示「Not saved — kept for this session only」。

出问题时：

- **证书错误：** 在 **集合 ▸ 连接** 里加入服务器的 CA，而不是关掉校验。
- **「This port does not speak TLS」：** URL 写的是 `https://`，而服务说的是明文 HTTP。改用 `http://` 重试。
- **路径缺失：** 那台服务器或 VPN 配置已被删除。请在**发送自**里另选一个。
- **保险库已锁定：** 在提示处解锁，然后重新发送。
- **变量未解析：** 从变量卡片把它加进环境、集合或全局变量。
